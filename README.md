# Rogue Commander

使用 Bevy 制作的守门生存塔防：控制英雄移动与闪避，让自动攻击、技能、召唤物和城墙共同抵挡敌群，在一局中组合英雄传承、羁绊与装备。

项目仍在开发。当前规则见[玩法设计总览](docs/game-design.md)，实际通过的版本、测试范围和剩余交付门槛见[发售体验验收](docs/release-readiness.md)。

## 玩法

- 从基础英雄开局，防守波次、精英与主线首领，获取资源并选择构筑。
- 城墙有有限耐久，倒塌后倒计时重建；英雄生命次数有限，最后一条生命耗尽则结束远征。
- 普攻、已学技能和终结技自动执行。职业有不同武器、被动和终结技，武器与技能表现随成长变化。
- 技能、羁绊卡点击即生效，支持连续选择；详细模式展示冷却、属性来源和升级收益，简洁模式保留关键差异。
- 羁绊收集不同成员组成组合，完成后获得能力并开放后续卡池。开局先完成固定的“启程”成员。
- 等级里程碑和转职果实提供征募机会；吞噬旧英雄后保留技能、装备与羁绊，并继承武器回响和英雄能力。
- 爬塔、金币试炼和上下营地提供可选压力与奖励；黑市装备可以进入装备栏，并按配方合成进阶装备。
- 战役逐章解锁，战果用于永久强化。局内构筑与永久进度分开保存。

设置中可切换英文／简体中文、卡牌说明模式、音乐和效果音音量，以及桌面窗口／全屏。首次远征提供可跳过、可重播的玩法指南。

## 运行

在仓库目录进入开发环境并启动：

```sh
nix develop
cargo run
```

`cargo run` 默认启动游戏。需要固定语言或种子时可使用：

```sh
ROGUE_COMMANDER_LANG=zh-CN ROGUE_COMMANDER_SEED=0xA11CE cargo run
```

不使用开发环境的玩家可查看[Linux桌面候选包说明](docs/desktop-release.md)，其中记录安装包位置、运行方法和独立验收范围。

## 键鼠操作

| 按键 | 操作 |
| --- | --- |
| `↑ ↓ ← →` | 移动 |
| `Shift` | 闪避 |
| `G` / `F` | 技能训练／羁绊获取 |
| `Q` / `W` | 爬塔／金币试炼 |
| `B` / `I` | 黑市／装备栏 |
| `H` | 羁绊图鉴 |
| `E` | 打开可用奇遇选择 |
| 数字键 | 选择当前卡牌 |
| `T` | 提高战斗倍速；减速和还原使用界面按钮 |
| `F11` | 切换全屏／窗口 |
| `Esc` | 关闭当前面板；战斗中暂停／恢复 |

界面按钮也可执行对应操作。点击英雄头像可查看属性；挑战面板可分别开启自动爬塔和自动金币试炼。触屏和手柄输入另见[手柄与输入说明](docs/controller-input.md)，实际设备覆盖以验收记录为准。

## 构建与验证

```sh
cargo fmt --all
cargo test --lib
cargo clippy --all-targets -- -D warnings
```

Linux发行构建见[桌面发行](docs/desktop-release.md)。其他构建入口包括[Web脚本](scripts/build-wasm.sh)和[Android脚本](tools/build_android.sh)；存在构建入口不代表最新浏览器部署、移动设备或各桌面平台已完成验收。

视觉和交互改动需要原生画面对照；测试、平衡与性能记录都必须注明版本和覆盖范围。第六章完整通关、更多配方的自然获取与合成链路、长期平衡与真实设备覆盖仍按[验收清单](docs/release-readiness.md)推进，当前不声明已达到Steam发售标准。
