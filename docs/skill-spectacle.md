# 技能强反馈

技能与终结技使用 HDR 与辉光渲染。明亮部分向周围散射光线，普通战场不会整体模糊；界面在场景后绘制，文字与冷却信息保持清晰。技能材质发光强度为10，终结技为12–16，未使用忽略发光属性的无光照材质。

效果读取真实技能、命中与状态：

- **火焰**：上升火柱、爆燃与飞散火星，持续燃烧期间重复表现。
- **冰冻**：冰晶、冰笼和破碎冰刺，冻结解除后停止生成。
- **控制**：头顶电弧标记眩晕，水系以水滴与浪纹区分。
- **增益**：金色符文和上升光束，表现战旗、法术及召唤强化。
- **病毒**：绿色分叉触须与孢子，随真实感染者扩散。
- **命中和弹道**：技能类型决定爆发形态与拖尾；等级提高体积和层数。

处决印保留原处决条件，新增6秒疫蚀，每秒造成技能伤害。单个感染者仅传播一次，最多传给两名邻近存活敌人，最多两代、全场最多32个感染者。等级提高伤害与传播范围，后代伤害逐代衰减。暂停冻结计时，死亡、到期与对象池复用时清理。该改动增加了实际伤害，并非只换颜色；本轮未做完整长局平衡重测。

技能瞬时特效上限600个，与终结技420个上限独立；共用网格和材质。高密度战斗下限制视觉生成，伤害和控制仍由原玩法系统独立结算。

验收使用 `skill-spectacle-{fire,frost,virus,buff,combo}`：真实5级技能、耐久敌阵、无测试机器人。为了单独观察技能，harness延长终结技冷却；断言技能实际造成伤害，特效出现，终结技未误参与。组合场景另外使用667×375英文窄屏。

## 等级与真实作用范围

范围技能的命中判定和对应特效随技能等级一起增长。统一成长倍率为1级1.0、3级1.5、5级2.0；潮汐水墙、光束宽度及地雷保留各自真实成长公式。雷霆万钧的实际区域半径依次为3.1、4.65、6.2米（1、3、5级）。近战召唤攻击距离、远程召唤射程、巨像牵引和震地范围也随等级变化；召唤体型采用适合各生物轮廓的独立成长。被动与辅助技能展示对应的层数、增幅、数量或持续时间，不伪造不存在的范围伤害。
