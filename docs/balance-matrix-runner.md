# 固定构建的批次复测

`run_balance_matrix.py` 在新批次目录保存可执行程序快照，计算快照 SHA256，并让所有局执行该快照。即使 Cargo 替换原二进制，后续局仍使用同一构建。摘要保留原程序位置、实际执行快照位置与校验值。

批次必须使用新的目录名；已有记录不会被重跑覆盖。发生中断时保留原批次，检查已完成收据，再以新名字补跑缺失的章节、职业和种子。未完成日志不是胜败证据。

5 项真实子进程测试通过，新增案例在第一局执行时替换原程序，并验证下一局继续执行同一快照、校验值正确；重复批次被拒绝，原收据保持不变。测试使用假程序验证调度与来源记录，不模拟游戏平衡。
