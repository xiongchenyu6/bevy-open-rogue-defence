# 发售体验验收

目标仍是持续提高游戏体验，达到可以上架 Steam 的单机游戏品质。这份清单约束实际游玩与交付质量，不代表已满足平台审核，也不因某一轮测试通过而缩小目标。

## 当前证据与下一步

| 体验 | 当前可确认事实 | 达到发售品质还需验证／实现 |
| --- | --- | --- |
| 战斗节奏 | 第一章40局前后对照、544项库测试和1,600帧原生场景已归档；低级伤害技能通过普攻蓄力与冷却施放 | 六章、多种子、全部12英雄与吞噬路线；新增永久属性后的难度边界；主动操作与支线奖励的取舍 |
| 音效 | 普攻、命中、终结技和首领提示均按真实时间限流；六档速度实际声音实例测试通过，见[音效规则](audio-feedback.md) | 实际设备听感、音乐／效果音独立设置、静音与偏好持久化 |
| 设置和暂停 | 设置支持语言、简洁／详细选牌；暂停支持恢复与失焦暂停，配置见 `settings.rs`、`selection_detail.rs`、`ui.rs` | 音量、显示选项、退出与返回章节入口；每项真实持久化、取消及已有弹窗的暂停归属回归 |
| 新玩家入门 | 章节选择、基础英雄征募、卡牌详细介绍已存在 | 从新存档实测理解成本；明确三条生命、城墙重建、资源用途与连续选卡的首次引导，允许老玩家跳过 |
| 视觉和输入 | 有原生桌面与窄屏受控战斗截图；52个自包含GLB及图标／立绘载荷校验通过 | 完整流程各状态可读性、遮挡与焦点；不同分辨率／缩放；长局特效峰值与帧时间；键鼠及计划支持的控制器操作 |
| 战役和存档 | `campaign_progress.rs` 实现章节解锁、战果货币及6种永久强化；原生文件与浏览器存储分开 | 新存档逐章通关和重启恢复；写入失败、损坏存档、结算重试与重复奖励；发行升级后的存档验证 |
| 内容差异 | 独立英雄、技能、羁绊、装备及营地系统存在 | 每个技能、首领和巨型营地敌人的实际机制／外观辨识，避免换数值或放大模型冒充新内容；全流程无占位资产 |
| 桌面交付 | 当前有原生调试二进制及 wasm／Android构建脚本；没有已验证的桌面发行包 | 干净机器启动、完整资源及第三方授权随包、发行构建、计划支持平台实测、性能／崩溃记录与最终安装验收 |

## 验收口径

- 当前源代码决定功能是否存在；历史文档或截图不能替代当前版本实际行为。
- 每轮改动需有对应的真实系统测试；视觉／交互问题必须重新捕捉并查看截图或录像。声音限流需统计实际 `AudioPlayer` 实体，解码测试不能代替真实设备听感。
- 平衡记录注明章节、难度、种子、成长策略、二进制与截尾状态，帧数到上限不能算通关。
- 发布候选版本需覆盖从首次启动到选择章节、征募、战斗、选卡、黑市、支线、死亡、结算、永久强化、重试和退出的完整流程。每个目标平台独立验收。
- 没有当前证据的项保持未完成。音量／显示设置、完整新手体验及干净机器发行包是明确剩余工作，不能把第一章验证称为已可上架。
