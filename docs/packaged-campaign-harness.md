# Continuing earned campaign runs

The public UI harness accepts CAMPAIGN_STAGE=0..5 and CAMPAIGN_SPEED=1/2/4/8/16/32. CAMPAIGN_CONTINUE=1 requires an existing checksum-valid game-created state, the requested chapter unlocked and every earlier chapter cleared. It reads the state and leaves game writes to the actual UI; it does not manufacture currency, health or clear flags. Fresh mode begins chapter zero in a new state directory.

Chapter clicks use inspected1280×720 card positions. StormSavant Level1 Strength is checked against20+2×the actual saved Strength upgrade level before battle and again after the real next purchase/restart. Strength purchase pricing follows the current Rust formula15+10L+5L²; level1 costs30and level2 costs55. The expected progress retains other upgrades and previous clear flags. A previously cleared chapter remains cleared even if a retry loses. The script still requires an actual victory to pass its final assertion.
