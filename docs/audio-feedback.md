# 高倍速战斗音效

战斗画面和伤害仍按玩家选择的1／2／4／8／16／32倍速推进，声音的最短间隔使用真实时间。听觉提示不应随加速堆到每帧一声；声音限流不减少攻击次数、技能伤害或终结技施放。

## 当前规则

| 声音 | 最短真实时间间隔 | 处理方式 |
| --- | --- | --- |
| 普攻发射 | 0.085秒 | 同一帧多个投射物只播一次；连续快速攻击按真实时间限流 |
| 终结技提示 | 0.5秒 | 提示被限流时立即消费，不保留待播队列；之后的新施放可重新发声 |
| 主线首领入场 | 0.35秒 | 同帧多个入场提示合并；连续入场按真实时间限流 |
| 命中、暴击、击杀与英雄受伤 | 各自已有真实时间间隔 | 保留原来的分通道限流、人数音量上限和音调变化 |
| 选卡、合成与集齐羁绊 | 不使用战斗提示限流 | 保留玩家操作及成长的即时声音反馈 |

发射样本实际长0.160秒、终结技样本0.950秒、首领样本1.450秒，均为48kHz单声道。间隔允许有限重叠，以保留持续战斗感；不是把声音完全截断或等待一个样本结束才播下一声。

旧发射声音使用加速后的游戏时间冷却，32倍速、60Hz持续新增投射物时每帧都可能发声。现在与命中通道统一按真实时间计算。这里只修改播放节奏，未改写声音素材，也未改动战斗数值。

## 验证方法

`src/game/audio.rs` 的真实 `play_feedback` 系统在独立Bevy应用中执行，测试逐帧新增真实投射物／首领组件和终结技序号，再统计实际创建的 `AudioPlayer` 实体。使用不同声音资产句柄区分通道；不加载声音输出设备，避免把运行机器是否接声卡混入逻辑验证。

- 六档速度各运行600帧／10秒真实时间，持续每帧新增投射物，应各创建100个发射声音实例，32倍速不会增长到600个。
- 12帧连续终结技提示应只产生一次播放；冻结游戏时间后继续等待真实时间，不补播旧提示；新终结技仍能发声。
- 60帧连续首领入场只应产生2–3次提示。
- 既有样本解码、音调变化范围和群体音量上限测试继续执行。

6项音效测试通过；全库回归547项通过、0失败、1项既有测试忽略。结果见[本轮验收记录](verification/audio-2026-10-06.txt)。实体计数验证播放节奏，不能代替真实设备的音量、削波、混音或长局听感验收。音乐／效果音独立音量、静音和持久化已接入，见[音量设置](audio-settings.md)。真实设备长局听感仍按[发售体验清单](release-readiness.md)验收。

复现：`CARGO_INCREMENTAL=0 nix develop --command cargo test --lib game::audio::tests -j1`。
