# 固定启程开局

前三次羁绊获取限定为力量启程、敏捷启程、智力启程。初次固定按此顺序展示三张，玩家可自由决定先拿哪张；随后只显示未获得的两张、最后一张。它们沿用已核实的各属性+20、木材+20；三张集齐后结算金币+100、木材+100并开放后续卡池。

刷新、放弃、稍后选择、英雄倾向和定向保底不能跳过启程，也不会把已拥有的卡塞回候选。启程完成前保留羁绊罗盘次数。完成后恢复原有前置条件、随机权重与去重规则。

卡名、卡面及解锁依据见[原图核查](dota-commander-reference.md)。开局固定规则按用户要求落实；不改抽卡价格或赠送三张卡。

`bond-opening`捕获从空收藏开始，通过实际抽取、刷新、稍后选择、预览和确认，断言候选3→2→1、每次仅获取一张、完成后开放三属性方向，同时检查候选卡未越出视口。
