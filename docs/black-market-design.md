# 黑市装备改版

黑市首先要让玩家看懂“是什么装备、买不买得起、对当前构筑有什么用”。旧界面把五段说明直接塞进商品按钮，装备没有视觉身份，属性文字抢走了选择的主次。

商品区改为五张图标卡：独立装备插画、品质边框、短名称、骷髅货币价格。装备和消耗品使用不同的类别提示；买不起仍可预览，已拥有与自动购买有明确状态。24种商品使用同一套独立绘制的图鉴，在黑市与装备栏中保持一致。

详细效果只在一处预览区显示，保留准确数值和作用条件，避免同屏重复五遍说明。鼠标悬停和手柄焦点更新预览；触屏先选中，再在预览区购买。自动购买是独立的小图标开关，提供说明；刷新显示图标和真实费用。钱包、补货时间和扣款反馈始终可见。

桌面使用横向商品陈列与下方预览，窄屏使用适配网格和可滚动详情。价格、购买规则、自动购买逻辑与正常随机库存不改。本轮是装备商店的视觉和交互改进，不以改动经济数值掩盖体验问题。

验收要覆盖中英文、桌面1280×720、窄屏667×375，商品默认／预览／买不起／已拥有／购买反馈／自动购买状态，以及手柄焦点。必须查看正式渲染截图，并检查真实扣款、重复购买保护与暂停恢复；仅生成插画或通过布局数值测试不算完成。
