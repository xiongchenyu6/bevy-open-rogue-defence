# 技能选牌说明

选牌页与设置页共享“详细／简洁”偏好。首次默认详细，切换立即保存，关卡重开和程序重启保留选择。

详细模式先显示等级、冷却或触发频率、当前与下一等级的实际伤害、范围或数量；其后显示属性系数、当前攻击／法术／召唤强度、伤害公式及控制、持续时间等效果。说明区域可以滚动；点击卡牌立即选取，无额外确认按钮。技能、羁绊和已积累的奇遇会连续开出下一轮。技能优先消耗免费点，用完后按当前价格逐轮扣金币，直到不足；羁绊逐轮扣木材。刷新保持连续选择，放弃或稍后结束；稍后保留已付费的手牌。按住指针不会误选新卡。简洁模式保留等级变化和一行核心效果。

主动伤害技能同时要求冷却结束与真实普攻蓄力；详细模式逐级列出这两项要求。R／SR／SSR／UR 一级分别需要 4／5／6／8 次实际普攻轮次，升级最多减少 2 次；多重箭、弹射及继承武器不重复计入蓄力。召唤补充、被动及受击触发沿用各自条件。

伤害和范围读取战斗使用的函数，包含当前强度增幅，显示的是扣除目标护甲、抗性之前的值。普攻次数触发、法术次数触发和被动技能不伪造施放冷却；召唤技能区分召唤冷却与每次攻击伤害。齐射、疫蚀、法术复制、旗帜、三相增益和命运骰子使用各自实际计算方式。

技能升级同步改变实际命中范围及对应特效。雷霆万钧1／3／5级半径为3.1／4.65／6.2米；其他技能按自身弹道、范围、召唤体型和数量展示成长。辅助技能展示实际增幅，不把没有伤害判定的效果写成范围伤害。

城墙塔说明明确标注：部署于城门顶部，城门倒下时停火并隐藏，重建后恢复；临时塔仍保留自身持续时间限制。
