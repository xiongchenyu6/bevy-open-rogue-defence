# 技能选牌说明

选牌页与设置页共享“详细／简洁”偏好。首次默认详细，切换立即保存，关卡重开和程序重启保留选择。

详细模式先显示等级、冷却或触发频率、当前与下一等级的实际伤害、范围或数量；其后显示属性系数、当前攻击／法术／召唤强度、伤害公式及控制、持续时间等效果。说明区域可以滚动；点击卡牌立即选取，无额外确认按钮。免费技能点、羁绊和已积累的奇遇会连续开出下一轮。羁绊按实际价格逐轮扣木材，直到不足；免费技能点耗尽后不自动花金币。刷新、放弃或稍后可结束连续选择，稍后保留已付费的手牌。按住指针不会误选新卡。简洁模式保留等级变化和一行核心效果。

伤害和范围读取战斗使用的函数，包含当前强度增幅，显示的是扣除目标护甲、抗性之前的值。普攻次数触发、法术次数触发和被动技能不伪造施放冷却；召唤技能区分召唤冷却与每次攻击伤害。齐射、疫蚀、法术复制、旗帜、三相增益和命运骰子使用各自实际计算方式。

技能升级同步改变实际命中范围及对应特效。雷霆万钧1／3／5级半径为3.1／4.65／6.2米；其他技能按自身弹道、范围、召唤体型和数量展示成长。辅助技能展示实际增幅，不把没有伤害判定的效果写成范围伤害。

城墙塔说明明确标注：部署于城门顶部，城门倒下时停火并隐藏，重建后恢复；临时塔仍保留自身持续时间限制。

验收：严格检查及原生构建通过，522项库测试通过（1项忽略）；桌面与手机11个实机场景、3310帧通过，覆盖连续技能点选、羁绊单次结算、UR进化和转职果实。详见[点卡即选验收记录](../screenshots/immediate-choices-validation.txt)。

连续选择验收：一次进入后完成三次真实羁绊点选，奇遇积累次数连续领取，525项库测试通过；13个原生场景共4670帧通过。详见[材质与连续选择验收](../screenshots/material-and-continuous-validation.txt)。
