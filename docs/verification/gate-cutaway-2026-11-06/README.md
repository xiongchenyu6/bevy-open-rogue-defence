# Hero visibility behind the gate

The previous932 live X11 session hid the hero after moving behind the gate; `actual-932-up-occlusion.png` preserves that observed negative. The new production presentation uses the main hero’s parallel orthographic viewing segment and the actual gate mesh-local Aabbs to request a150ms cutaway. It covers the imported gate, towers and procedural walls/doors. Dedicated material clones prevent shared pillars/camps from fading; leaving the occlusion restores the exact original material handles and original mesh-level shadow flags. No Core/Hero Transform, gameplay HP, collision or gameplay RNG is written by this presentation system. Bounds are conservative candidates rather than a per-pixel visibility oracle.
