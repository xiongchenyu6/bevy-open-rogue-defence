# 实际配方选择输入诊断

此前新版 495 包的 C6 公开路线在第三件装备时严格失败：依次点击三个已持有图标，详情都仍显示 Hardened Plate。该自然路线失败没有被本测试覆盖或判为通过。本轮只隔离诊断同一装备面板的六个配方按钮是否可以切换明确选择。

使用断网 Docker、只读不可变 495 包、冻结助手快照。新状态只复制真实积累的原始 campaign.save（SHA-256 `da5bf0a9ca3f4032a265425f9989bda292d8c0c2622848157df6d2c0223ba825`）；无教程偏好、装备、材料、战功或库存注入。实际通过教程与基础英雄进入战斗，打开空背包并切到 Forge，没有购买或合成。

先对六张配方各发送一次普通 `xdotool click 1`，再依次对六张卡片各发送一次 mouseDown，等同一完整截图中的选中标题精确匹配该卡片实际名称后，在 finally 中 mouseUp。按下期间不重复点击、不发送未知输入；十秒期限同时检查读取前后。每轮保存原始截图、标题、卡片文字与单调时钟输入时间。

## OCR 诊断与限制

[首次尝试](initial-ocr-failure/runtime.log) 的前四张普通点击通过。Night Crown 实际已选中，但它的材料换行使标题上移，原 `310x38+744+219` 裁剪包含材料行，严格标题解析拒绝；并非选择按钮失败。[失败画面](initial-ocr-failure/ordinary-4-after.png) 保留。第二次脚本只针对配方改用 `310x28+744+217`，没有修改生产解析器或放宽名称。重新启动已先于上级“先离线验证”消息发出；随后立即离线核对前五张已获得截图。已有桌面 World Engine 原生图是中文，未用英语 OCR 结果冒充身份验证。

最终新增英语 World Engine 画面后，[离线复核](offline.log) 对全部 12 张归档截图严格匹配成功；[脚本](offline.py) 可在相同只读 Docker OCR 镜像中重跑。

普通点击也全部成功，不能据此认定 C6 失败由零持续时间输入造成；本测试未复现生产选择状态卡死。六个配方使用实际界面选择，但不是三件已持有装备的自然路线验收。未改变生产游戏代码或公开路线助手选择逻辑，未启动新的完整自然合成/C6 重试。
