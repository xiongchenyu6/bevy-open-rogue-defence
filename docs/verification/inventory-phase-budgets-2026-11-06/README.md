本轮修正助手前置条件与时间分配，不改变游戏平衡、游戏时钟、装备规则或生产输入逻辑。

## 有限阶段预算

关闭操作记录 operation_start、header_observed、mouseDown/dispatch_finished、每次 held_observation、mouseUp 和 operation_end 的单调时间。整体截止时间在读取标题之前检查，并在标题读取后再次检查。持续按下的十秒预算从按下派发阶段开始，且始终受整体操作剩余时间约束；标题 OCR 不再提前消耗十秒按下预算。发生异常或超时仍释放，释放后保留原完整新截图的严格“装备标题与 Close 均消失”断言。

Forge 给关闭操作二十秒整体预算；同档重启使用其剩余总预算与二十秒的较小值。C6 使用当前访问的真实剩余截止时间，按下阶段仍单独封顶十秒。

C6 访问基础预算从 120 调整到 140 秒，每件装备额外二十秒不变，最多十二次访问不变：累计暂停上限为 `12×140 + 20×(1+…+12) = 3240` 秒，内部总上限为 `1800+3240 = 5040` 秒，仍小于既有外部 5400 秒。没有无限重试或延长游戏内倒计时。

重启现在复用同一小型装备关闭函数，仅改助手；原真实空背包、Strength 30、实际恢复倒计时与正常退出检查保留。
