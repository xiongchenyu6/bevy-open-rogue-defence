# 中文分词与界面排版更新

当前固定的Bevy 0.19.0使用Parley 0.9.0。这个版本通过不加载复杂文字词典的构造器进行词分割，中文属于ICU内部的中文／日文共用分组，所以日志中的`ja`也会由中文触发。上游后续提供了[复杂文字分割开关](https://github.com/bevyengine/bevy/pull/25674)，当前固定版本尚不能直接使用。

本轮保留引擎版本，仅在Parley的词分割构造器启用已有编译数据中的词典。源码、原始文件哈希和许可证保留在[vendor/parley](../vendor/parley/LOCAL_CHANGES.md)。没有删中文，也没有关闭或过滤错误日志；正常中文换行规则保持不变。升级到提供官方开关的引擎后，应删除本地依赖覆盖并直接使用该开关。

界面文字、字体及响应式布局现在仅在值真正变化时标记更新。普攻与资源数字、复活倒计时、血量、冷却、价格、选卡介绍、语言、音量和显示模式仍正常刷新；同样的内容不会每帧重新触发排版。城门标题和血量先组装成完整文字，再一次比较，避免先替换标题、再追加血量导致重复变更。

## 验收口径

基线保留提交`d9928e5`的原生捕捉二进制，使用同一种子、100帧导航场景和隔离偏好目录。中文桌面1280×720与窄屏667×375各记录8,012条ICU分词错误；英文桌面因语言按钮包含中文记录3条。基线场景均实际通过导航断言。

新增`text-idle`加载真实游戏及渲染系统，暂停战斗，分别统计中文HUD、中文设置及英文设置各61帧的`Changed<Text>`、`Changed<TextFont>`及实际`Changed<TextLayoutInfo>`。探针实际点击音量和语言按钮，检查对应文本内容和变化标记。静止阶段没有变化不能替代这些动态输入检查。

最终563项库测试通过（0失败、1项忽略），严格Clippy、三个原生二进制构建和格式检查通过。桌面与窄屏各320帧探针、三组各100帧导航对照、600帧实际战斗，共1,540帧全部通过。
