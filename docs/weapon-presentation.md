# 十二英雄普通攻击

十二名英雄分别设计普攻轮廓、动作、飞行和命中反馈。以下表现由真实普通攻击驱动，伤害、攻击距离、命中角度、穿透与羁绊结算沿用现有逻辑。

| 英雄 | 普攻表现 |
| --- | --- |
| 山铠守卫 | 宽厚锯齿裂刃，由内向外挥出；命中裂地与石屑。 |
| 曜光先锋 | 倾斜的双层金色交叉斩；命中十字光芒。 |
| 潮界行者 | 两重弯曲浪刃交错挥动；命中双卷水纹。 |
| 裂隙舞者 | 三段错开的折线刀光与残影；命中交叉斩痕。 |
| 铁血狂战 | 大幅外扫的重斧月牙；命中重劈与飞溅碎片。 |
| 虚空收割者 | 向内收割的双层镰钩；命中内收紫色弧线。 |
| 烬弦猎手 | 火焰倒钩箭、双股火尾；命中爆燃。 |
| 森垒机巧师 | 粗重三翼机械弩矢、分段光轨；命中机械碎片。 |
| 玄霆术师 | 分叉雷矛、闪动电弧拖尾；命中电光散射。 |
| 灵契牧者 | 彗星头、弯曲尾须与双股残迹；命中灵光扩散。 |
| 星筹浪客 | 旋转星镖与旋转残影；命中星色碎片。 |
| 霜脉先知 | 冰晶长矛与下落碎晶；命中放射冰晶碎裂。 |

法师和弓弩出手保留短暂弹体轮廓，贴脸命中也能看见释放动作。近战在接触帧检查目标距离和角度，命中特效只在真实命中后出现；挥空保留挥砍动作。

网格和材质在启动时共享创建；发光使用HDR材质与Bloom。装饰碎片最多320个，待处理出手/命中提示最多48条，饱和时省略装饰。暂停冻结特效，结束清理；弹体池每次使用会更新武器网格与表现状态。

## 验收

`capture frames <directory> 210 attack-<hero> 0xA11CE <size>` 支持全部十二英雄：`storm/ember/stone/spirit/tide/star/frost/iron/rift/grove/solar/void`。镜头与测试靶位于战场中央，近战主目标距离1.3，远程目标距离5，测试靶100000生命且不造成伤害；没有城门遮挡。

场景清空已学技能、延长终结技冷却、移除测试机器人，保留英雄原生被动。第205帧检查实际敌人掉血、武器特效出现，以及技能、终结技、机器人仍被禁用。桌面1280×720与窄屏667×375各录十二段，录像不含音频；不代表手机真机性能或整局平衡测试。
