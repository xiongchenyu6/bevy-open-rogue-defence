# 显示与远征导航

设置页底部提供返回远征、章节、窗口／全屏和退出游戏。设置入口在章节选择页同样可用。窄横屏沿用同一行按钮，不增加页面高度。窗口／全屏和退出按钮只在原生版本显示；浏览器仍通过浏览器控制窗口。

原生显示按钮立即切换窗口与当前显示器上的无边框全屏；F11在设置页及游戏内都可切换。返回窗口模式恢复进入全屏前的窗口尺寸与位置。显示偏好独立保存于用户配置目录的 `rogue-commander/display`，下次启动应用；损坏内容回退窗口模式，启动时不覆盖原文件。保存失败时本次切换仍生效，设置页显示偏好无法保存。验收通过 `ROGUE_DISPLAY_SAVE` 指定隔离路径。

点击章节或退出会先展示离开提示，说明当前远征无法继续、构筑和未使用资源会丢失，已保存战役进度保留。取消按钮或Escape关闭提示，保持设置页和此前远征不变；不会同时把远征取消暂停。离开提示打开时，设置页的Escape关闭逻辑不会越过提示执行。

确认章节后，沿用真实远征重置流程：清理敌人、弹道、临时能力、选卡和挑战，保留场景及永久战役属性，再打开章节选择。放弃远征不会产生通关奖励。新章节开始时仍走已有新局初始化。确认退出发送引擎的正常退出事件。

## 验收范围

本轮检查真实窗口组件、实际偏好文件和真实按钮处理；原生截图场景依次打开设置、取消返回章节、取消退出、确认章节，核对敌人清理、永久进度、随机种子和暂停状态。最终558项库测试通过，0失败、1项忽略；所有目标严格Clippy、原生构建及格式检查通过。五个最终原生截图场景共560帧全部通过。

真实Winit程序在隔离Linux/X11桌面测试：实际点击章节页的设置入口，F11由1280×720切到1600×900，再恢复原尺寸和位置；独立重启读取全屏偏好；实际点击退出确认后进程返回0。保存路径故意设置为目录时，显示切换仍生效、目录保留，页面显示保存失败。开发资源通过`BEVY_ASSET_ROOT`提供，尚不是独立发行包验收。
