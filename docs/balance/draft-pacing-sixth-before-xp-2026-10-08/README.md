# Sixth-chapter baseline before experience pacing change

All six stationary active builds, zero permanent training, finished as valid wins with zero deaths. All reached level 60. Warrior minimum living health fractions: 0.267 / 0.201; archer: 0.962 / 0.928; mage: 0.570 / 0.881. This contradicts the goal of needing accumulated power or better play for the strongest chapter in this limited sample.

The same enemy experience is currently multiplied by chapter reward scale (up to ×2), which accelerates in-run attribute growth alongside the harder enemies. The candidate removes this experience multiplier while retaining higher gold rewards. It is still undergoing paired full-run verification; no balance completion claim is made.
