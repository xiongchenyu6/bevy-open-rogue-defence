# Rogue Commander 当前玩法设计

本页定义当前玩法的结构、玩家决策和系统边界，作为各专题文档的入口。具体数值以当前配置和卡牌说明为准；功能实现与实际验收分开记录，交付状态以[发售体验验收](release-readiness.md)为准。

## 核心体验

玩家守住一条从敌方魔窟通向城墙的道路，在自动战斗中构筑英雄、技能、羁绊和装备。移动、闪避、挑战时机与选牌是主要决策；普攻、已学技能和终结技自动执行。

局内成长要形成可辨识的变化：武器从基础形态逐步强化，技能升级改变威力与表现，集齐羁绊开放后续组合，吞噬英雄扩展攻击与能力。奖励既要改变构筑，也要在图标、动作和战场反馈中体现。

## 一局循环

1. 选择已解锁章节，从基础英雄中选择开局职业。
2. 防守波次，获取经验、金币、木材和击杀信用，升级并安排构筑。
3. 在技能与羁绊选择间权衡，按需挑战爬塔、金币试炼和上下营地。
4. 在等级里程碑或使用转职果实时征募新英雄，继承旧英雄能力。
5. 从黑市购买装备，收集材料并合成进阶装备，迎战主线首领。
6. 击败最终首领后进入战果刻印，再结算战果与章节进度；英雄生命耗尽则结束本次远征。

技能、羁绊等选牌点击即提交。连续选择通过队列衔接，在资源和条件允许时进入下一手；刷新、放弃、稍后选择和替换构筑各自遵守对应规则。

规则入口：[选牌与成长](../src/game/progression.rs)、[选牌提交](../src/game/progression.rs#L1230)、[战果刻印](archive-hud.md)。

## 城墙、英雄与召唤物

- 城墙横跨主路，拥有有限耐久，承担正面拦截。城墙倒下不判负，会显示重建倒计时，之后恢复耐久；重建次数不限。
- 英雄拥有有限生命次数，剩余生命包含当前生命。致命伤先结算免死能力；仍有生命时等待复活，最后一条生命耗尽则失败。
- 移动召唤物在城墙外集结，面向敌方，发现目标后主动交战；驻墙炮塔与城墙状态联动，城墙损毁期间停火。
- 英雄可以移动、闪避和进入支线路径。城墙提供防守支点，不能代替玩家处理所有危险。

规则入口：[死亡与重建](../src/game/combat.rs#L380)、[城门倒计时](gate-countdown-labels.md)、[召唤物阵形](summon-formation.md)、[召唤物进攻](summon-assault.md)。

## 职业、属性与普攻

职业由主属性、武器攻击、被动和自动终结技共同区分。近战使用挥击与接触判定，射手发展多重射击和弹射，战士发展分裂攻击；继承武器仍按各自射程和攻击方式寻找有效目标。

英雄属性页展示基础、攻击和防御信息，包含暴击、吸血、物理与法术穿透等构筑结果。卡牌预览结合当前属性说明收益，避免只显示技能名称。

表现遵循等级分档：初始武器保持清晰克制，升级后逐步增加形态、轨迹和命中层次。蓄力、挥击、接触和收招要与实际伤害一致；震动、短闪、受击动作与停顿不能让高攻速或加速战斗失去可读性。

规则入口：[普攻表现](weapon-presentation.md)、[英雄属性与倍速](hero-attributes-and-speed.md)、[自动终结技](automatic-ultimates.md)、[职业普攻](../src/game/basic_attacks.rs)。

## 征募与吞噬继承

开局只提供基础英雄。达到 **10、20、40级**时产生征募机会；部分羁绊完成后奖励转职果实，使用果实可额外征募。选择有效候选时才消耗对应机会或果实。

征募替换当前英雄，同时保留局内构筑：已学技能、羁绊、装备和已取得的技能进化继续存在。旧英雄属性形成传承，旧武器以轮换回响参与攻击，旧被动与终结技继续按各自规则执行。新增英雄起手技能和技能容量由征募记录管理，不能反复征募同一英雄刷取容量。

吞噬属于本次远征的成长。返回章节、重试或开始新局时，应清理这些局内记录。

规则入口：[征募来源与里程碑](../src/game/resources.rs#L9)、[征募执行](../src/game/hero.rs)、[英雄继承](hero-fusion.md)、[继承武器射程](fusion-reach.md)。

## 技能训练与进化

技能训练优先消耗免费训练次数；没有免费次数时按当前训练价格花费金币。新技能、升级、替换和后期进化都通过真实卡池与容量规则提供，候选受种子、阶段、已持有内容和构筑条件约束。

普通技能升级改善伤害、控制、数量或范围，并按技能类型改变表现。满级UR技能提供互斥的进化方向；其他技能的后期升华受等级、羁绊完成度或爬塔进度限制，不能把所有成长都变成无条件重复加级。

选择页提供简洁与详细两种模式。详细说明需要写清冷却、伤害类型、属性来源、当前值与升级后的变化；简洁模式保留核心作用和选择差异。

规则入口：[技能选择说明](skill-selection-details.md)、[卡池多样性](skill-draft-variety.md)、[升级反馈](skill-upgrade-feedback.md)、[UR进化](ur-evolution.md)、[进化条件](../src/game/skill_evolution.rs)。

## 羁绊收集与组合池

羁绊由唯一成员卡组成，已持有成员不靠重复获取叠层。开局前三次获取固定为“启程”的三张不同成员；完成后进入更广的组合池。

成员提供自身效果，组合完成再授予完整羁绊能力，并可开放后续羁绊、提供转职果实或改变构筑路线。后续池同时受前置组合与阶段条件控制。槽位满时通过明确的替换选择调整构筑，不能悄悄覆盖原组合。

完成反馈应明确展示完成的组合、奖励和新开放内容，让玩家知道这次收集改变了什么。

规则入口：[固定开局羁绊](opening-bonds.md)、[后续羁绊池](bond-pool-expansion.md)、[完成反馈](bond-completion-feedback.md)、[成员与效果目录](../src/game/bond_catalog.rs)。

## 波次、首领与可选挑战

主路压力由普通波次、集中来袭、精英词缀和首领行为共同组成。精英与首领需要有可识别的攻击节奏、危险预警和应对窗口；不能只依赖血量增长表达难度。

爬塔和金币试炼是独立的局内挑战，分别管理开放条件、目标、奖励和冷却，可手动启动或启用自动挑战。它们会争夺玩家的输出与注意力。

上下营地提供可选战斗。玩家探索后可接受首领战，或领取较小奖励离开；选择战斗时营地敌人进入战场，使用独立的技能与阶段机制。支线奖励可以增强普攻和触发能力，但需要承担额外压力。

规则入口：[主线首领](../src/game/bosses.rs)、[试炼执行](../src/game/trial.rs)、[职业与自动挑战](career-and-auto-trials.md)、[营地设计](adventure-camps.md)、[营地首领配置](../src/game/encounter_bosses.rs#L53)。

## 资源、装备与合成

| 资源 | 主要决策 |
| --- | --- |
| 经验 | 英雄等级、成长与征募里程碑 |
| 金币 | 付费技能训练与部分成长选择 |
| 木材 | 羁绊获取与组合路线 |
| 击杀信用 | 黑市装备、消耗品和刷新取舍 |
| 战果货币 | 局外永久强化 |

黑市展示插画、品阶、价格和可检查的装备效果。装备进入装备栏并持续生效，换英雄后保留；消耗品按自身规则处理。

合成按配方消耗已拥有的材料，生成新的装备条目，保留材料效果并追加配方收益。进阶配方可以使用已合成装备。合成品应有独立图标与明确的材料、效果和已完成状态，避免玩家只看到数值或复用原材料外观。

规则入口：[黑市设计](black-market-design.md)、[装备栏](equipment-inventory.md)、[合成可读性](forge-readability.md)、[合成执行](../src/game/crafting.rs#L220)。

## 战役与永久成长

战役包含六个章节，通关后开放后续章节。结算发放战果货币，永久强化可改善力量、敏捷、智力、生命、攻击和法术威力；开局应用一次，后续征募保留本局已应用的成长。

永久存档与局内状态分离。重试和返回章节清理技能、羁绊、装备、英雄继承、试炼和临时效果，保留章节与永久强化。保存失败应保留原存档并提供重试，不能重复结算奖励或把未保存状态伪装为成功。

规则入口：[战役进度](campaign.md)、[永久进度结构](../src/game/campaign_progress.rs#L19)、[局内重置](../src/game/run_reset.rs#L37)、[保存失败恢复](campaign-save-retry.md)。

## 设置、输入与交付

设置支持英文／简体中文切换、选牌简洁／详细模式、音乐与效果音独立音量、静音和偏好保存。桌面提供窗口／全屏、暂停恢复、返回章节与退出；操作反馈和提示需要同时适配鼠标、触屏与手柄。

资源未就绪时展示真实加载状态；失败后允许重试，不能提前进入缺模型或缺界面的战斗。音频设备失效时保留可恢复的音乐状态，避免积压旧效果音，重连按真实时间进行。

桌面、Web和移动端需要分别验收，存在构建入口或布局分支不等于已经满足各平台交付要求。

规则入口：[设置与导航](settings-navigation.md)、[手柄输入](controller-input.md)、[远征加载](expedition-loading.md)、[音频恢复](audio-device-recovery.md)、[桌面发行](desktop-release.md)。

## 当前验收边界

功能目录用于描述规则，不能代替实际运行证据。当前第六章完整通关、最新安装包的同局自然获取／合成后恢复战斗与退出／重启链路仍需完整复验；脚本中断不算游戏胜负，也不算整局通过。

更多种子、英雄与吞噬路线、长期经济和难度曲线、长局特效峰值、物理音频与手柄设备、其他桌面平台及真实Steam安装仍是交付门槛。当前证据、对应版本和未完成项统一维护在[发售体验验收](release-readiness.md)，不在总览重复保存过期风险清单。
