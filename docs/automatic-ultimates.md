# 自动终结技

终结技不再需要按空格或点击。冷却完成且存在可用目标时自动施放；近战能力检查实际范围，召唤能力检查空余召唤位，修复城门的能力也可因城门受损触发。未选定英雄、死亡、暂停、结束、空场且无支援需求时不消耗冷却。旧的手动请求字段与输入路径已移除。

战斗HUD不显示终结技图标、冷却条、倒计时或悬浮提示。终结技继续按既定规则自动施放，玩家无需操作。英雄属性从独立头像入口查看。

| 英雄 | 玩法与视觉区分 |
| --- | --- |
| 玄霆术师 | 连续10次定点落雷，分叉闪电从上方击中敌群。 |
| 烬弦猎手 | 5轮扇形烈焰箭雨，每轮5发。 |
| 山铠守卫 | 岩阵压制附近敌人并修复城门，石柱依次升起。 |
| 灵契牧者 | 召来最多6个环绕战灵，持续协同射击；受共享召唤上限约束。 |
| 潮界行者 | 3段推进浪潮，造成范围伤害、浸湿与减速，区别于冰冻。 |
| 星筹浪客 | 根据城门耐久与敌群数量选择修复、范围打击或资源奖励，五芒星汇聚。 |
| 霜脉先知 | 冻结普通敌人、减速首领，随后4次寒冰爆发与雪花冰阵。 |
| 铁血狂战 | 恢复部分已损失生命，6次近身旋斩，以双重刃弧表现。 |
| 裂隙舞者 | 8次敌人位置的小范围裂隙斩击，交错刀光连接目标。 |
| 森垒机巧师 | 修复城门并发动6次定点炮击，堡垒至落点的炮火轨迹。 |
| 曜光先锋 | 治疗自身与城门、减速敌人并连续曙光打击，金色盾墙。 |
| 虚空收割者 | 固定中心持续牵引敌人并进行5次打击，首领受到较弱牵引；收缩虚空环。 |

移除了统一的开场圆环。各终结技的伤害和控制由玩法系统结算，视觉效果单独接收施放与脉冲通知，不重复结算伤害。特效共用网格和材质，最多24条待处理通知、420个瞬时部件；暂停冻结、结束清理。音效根据真实施放序号触发，调整冷却不会误播放。

自动施放及部分能力行为已改变，因此本轮不沿用旧版长局胜率结论。这里验证的是施放规则、行为区分和画面，不是完整25分钟平衡。

验收场景为 `ultimate-{storm,ember,stone,spirit,tide,star,frost,iron,rift,grove,solar,void}`，每场210帧。明确的测试敌阵保持高耐久，关闭测试机器人，不写入任何手动施放请求；冷却从1秒自然归零，断言自动施放一次并持续冷却。
