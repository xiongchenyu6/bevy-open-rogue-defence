# 羁绊集齐反馈

集齐最后一张卡是一次构筑完成：卡片图标汇合成家族徽章，配合金色波纹与独立的递进音效；随后显示刚获得的组合效果，以及新开放的羁绊池或转职果实。具体效果、后继卡池和果实数量直接取自现有羁绊目录，不另设奖励规则。

庆祝持续4.8秒，以真实时间计时，三倍战斗速度不压缩阅读时间。面板不接管输入；选择、设置等暂停页面打开时隐藏并停表。多个羁绊同时完成会依次展示，技能升级提示等待羁绊庆祝结束。初始载入时已有的完整羁绊不重播。

完成徽章长期保留在战斗HUD，显示金色底色与勾号。鼠标悬停可看详情，点击或触屏轻点后固定详情，再点同一徽章或外部关闭。详情显示效果已生效、羁绊槽已释放和解锁卡池。果实自动到账，现有果实征募入口用于预览转职，确认新英雄时才消耗。

验证场景使用明确的测试前置收藏，再通过真实抽卡、卡牌点击取得最后一张卡：

- `bond-completion`：启程完成，验证力量、敏捷、智力卡池开放。
- `bond-completion-fruit`：战意完成，验证一枚果实只到账一次。

每个场景跑270帧，验证预览不提前庆祝、确认后效果/奖励/槽位、面板和子元素在视口内、庆祝结束、徽章保留以及触屏详情的展开/关闭。额外检查技能、闪避、终极技能、速度按钮均在视口内且不被庆祝面板遮挡。窄屏满收藏时，果实与抽卡入口并排，底部控制栏固定在安全边界，避免上方内容挤走战斗按钮。这是最后一张卡的交互验收，并非完整长局平衡测试。

音效为本项目生成的原创合成音，无外部采样；可用 `python tools/generate_bond_chime.py` 重建。
